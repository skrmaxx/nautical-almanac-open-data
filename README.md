# Nautical Almanac: open data

This repository holds data the Nautical Almanac Android app uses whose licences ask for an open copy.

| Folder | What | Licence |
|---|---|---|
| [`sea-lanes/`](sea-lanes/) | The sea-lane network of the Port to port tool, derived from Eurostat's MARNET, with layers from AIS ship traffic (World Bank / IMF, CC BY 4.0) | EUPL-1.2 |

Each folder has its own README, saying where the data comes from, what was changed and how to rebuild it.

The app's other data sources are credited in the app itself, under Port to port › Data and licences. They ask for
credit only.

**Not for navigation:** use official charts and publications.
